Storyvan

Storyvan est un logiciel personnel qui tourne sur l'ordinateur de son propriétaire (serveur local, adresse 127.0.0.1). Il sert à fabriquer des vidéos courtes verticales (YouTube Shorts) : scénario, montage, voix et export du fichier vidéo. Rien n'est hébergé par Storyvan : les projets et les fichiers restent sur l'ordinateur de la personne.

Utilisation de YouTube

Si le propriétaire le décide, il peut relier sa propre chaîne YouTube dans l'écran « Export ». Storyvan demande alors une seule autorisation à Google : envoyer des vidéos sur sa chaîne (https://www.googleapis.com/auth/youtube.upload). À chaque clic sur « Envoyer », Storyvan transmet à YouTube la vidéo, son titre, sa description et sa visibilité choisie. Storyvan ne lit ni les vidéos existantes, ni les statistiques, ni les données personnelles du compte.

Les données restent sur l'ordinateur de l'utilisateur et ne sont envoyées qu'à YouTube. Détails : règles de confidentialité.

Google API Services User Data Policy

L'utilisation par Storyvan des informations reçues des API Google respecte la Google API Services User Data Policy, y compris les exigences d'utilisation limitée (« Limited Use »).

Storyvan

Storyvan is personal software that runs on its owner's own computer (a local server at 127.0.0.1). It is used to make short vertical videos (YouTube Shorts): script, editing, voice-over and export of the video file. Nothing is hosted by Storyvan: projects and files stay on the user's computer.

How Storyvan uses YouTube

If the owner chooses to, they can link their own YouTube channel on the "Export" screen. Storyvan then asks Google for a single permission: uploading videos to their channel (https://www.googleapis.com/auth/youtube.upload). Each time the owner clicks "Send", Storyvan sends YouTube the video file, its title, its description and the chosen privacy setting. Storyvan does not read existing videos, analytics or any personal account data.

Data stays on the user's computer and is only sent to YouTube. Details: privacy policy.

Google API Services User Data Policy

Storyvan's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
